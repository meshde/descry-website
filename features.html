Features

Everything you need to actually review the change

Not another diff viewer with syntax highlighting. Descry decomposes a PR into the logical work it does, and stays with you while you work through it.

Walkthroughs

Flows instead of files

Descry groups every changed hunk into a named flow — a piece of the change with its own job — and orders its steps the way the code actually runs, not the order files happen to sort in.

  • Each flow explains how it serves the PR's overall goal
  • Pure plumbing (imports, DI wiring) is marked and gets out of your way
  • Anything not worth a separate callout still shows up, just grouped
Flow 1 — Add retry to the sync job

The sync job now retries a transient fetch failure instead of giving up immediately, so one flaky request doesn't fail the whole run.

Chain diagrams

See the call chain, not just the files

A flow's "View Chain Diagram" button opens the real call graph behind it — who calls whom, in order. Hover a node for its file and what changed there; click it to jump straight into that function's own diff.

  • Built from the actual code graph, not guessed from file names
  • Every node is navigable, including nodes outside the current step

Ask Descry

Ask about the code you're looking at

A chat panel scoped to the exact line, step, or flow you've got open — grounded in your real codebase, not a generic summary of the diff text.

  • Answers link back to the step or flow they reference
  • Live-reviewed by your own coding agent when the walkthrough came from one
Does this handle the case where the file uses commas as a thousands separator?
descry

Yes — it only treats comma as the decimal point when the file's own delimiter is a semicolon. Everything else keeps comma as a thousands separator.

Agent integration

Let your coding agent walk you through its own change

Descry ships an MCP server. Right after Claude Code or Codex finishes implementing a plan, it can submit a walkthrough of exactly what it changed — then stay live to answer your follow-up questions itself, with full context on the repo.

  • Works on uncommitted changes, not just pushed branches
  • No separate LLM key needed — it rides on your agent's own session
