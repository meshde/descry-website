Getting started

From install to your first walkthrough

Descry works two ways: point it at a PR yourself, or let the coding agent you're already using generate the walkthrough right after it finishes a change. Both end up in the same place.

1. Install Descry

1

Download the app

Grab the latest build from the releases page. Descry is a desktop app for macOS and updates itself in place after that.

2

Add a repository

In Settings → Repositories, add the local folder of the repo you want to review. In Settings → Version Control, connect GitHub so Descry can list its open PRs.

3

Add an LLM provider (optional)

If you want Descry to classify a PR on its own — without a coding agent — add a provider key under Settings → LLM Providers. Skip this if you're only going to generate walkthroughs through Claude Code or Codex (see path B below).

2A. Review a PR directly in Descry

1

Click "+ New Review"

Pick the repo and the open pull request you want to review.

2

Wait for the walkthrough

Descry builds the code graph for the PR, groups the diff into flows, and opens the review once it's ready.

3

Work through it flow by flow

Open a chain diagram where one's shown, ask Descry questions inline, and leave comments anchored to specific lines.

2B. Generate it from Claude Code or Codex

1

Connect the Descry MCP server

Descry ships an MCP server (descry-mcp) that any MCP-capable agent can connect to — add it the same way you'd add any other MCP server in your agent's settings.

2

Ask for a walkthrough once your change is done

Right after implementing a plan — committed or not — ask your agent to walk you through it in Descry. It classifies its own diff into flows and submits the review.

3

Ask questions, live

Open the review in Descry and ask away — your agent is listening and answers from inside the same repo it just changed, not a cold read of the diff.

Ready when you are

Download Descry and point it at your next PR.
