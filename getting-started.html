Getting started

From install to your first walkthrough

Descry is driven by the coding agent you're already using — Claude Code or Codex generates the walkthrough itself, right after it finishes a change, and stays around to answer your questions on it.

1. Install Descry

1

Download the app

Grab the latest build from the releases page. Descry is a macOS desktop app (Apple Silicon only, for now) and updates itself in place after that.

2

Set up a workspace

On first launch, create a workspace — it's what holds your repositories and settings.

3

Add a repository

In Settings → Repositories, add the local folder of the repo you want reviews for.

2. Generate your first walkthrough

1

Connect the Descry MCP server

Descry ships an MCP server (descry-mcp) that any MCP-capable agent can connect to — add it the same way you'd add any other MCP server in your agent's settings.

2

Ask for a walkthrough once your change is done

Right after implementing a plan — committed or not — ask your agent to walk you through it in Descry. It classifies its own diff into flows and submits the review.

3

Work through it, live

Open the review in Descry: step through each flow, open a chain diagram where one's shown, leave comments anchored to specific lines, and ask questions as you go — your agent is listening and answers from inside the same repo it just changed, not a cold read of the diff.

Ready when you are

Download Descry and point it at your next PR.
